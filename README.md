# Данный проект представляет собой ядро для интернет-магазина

## Описание:

На данный момент приложение создает классы товаров Product и Category

## Установка:

1. Клонируйте репозиторий:
```
https://github.com/PavelSergeevichA/Project_OOP
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
## Тестирование:

Проект покрыт тестами pytest. Для их запуска выполните команду:
```
pytest
```
